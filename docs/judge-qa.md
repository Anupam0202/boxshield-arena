# Judge Q&A

**Why is this more than prompt engineering?**
BoxLang validates data, authorizes actions, enforces budgets and approval, signs state, evaluates deterministic invariants, calculates scores, and generates evidence. The model cannot bypass those controls by changing prose.

**How do you prevent the defense from refusing everything?**
Five benign controls produce a separate Utility Score. Regressions remain visible and can invalidate an otherwise improved shield.

**Is the before/after comparison fair?**
The adaptive attack runs against the baseline, then IDs, payload bytes, model settings, target data, and corpus version freeze. Only the defense policy changes.

**Does it attack arbitrary agents?**
No. The submitted MVP includes one synthetic target and a local adapter interface. Arbitrary URLs are intentionally absent.

**Why not let Gemini call tools directly?**
Native Gemini capability and bx-ai adapter capability are different. The portable path is a structured proposal followed by BoxLang authorization. Native tools are optional after a real capability smoke test.

**Is it OWASP certified?**
No. The corpus is OWASP-informed and maps selected cases to relevant 2026 categories.

**What remains?**
More targets, repeated live samples, globally durable rate limiting, broader corpus review, and a publishable ForgeBox package.
